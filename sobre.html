Projeto integrador

O Projeto Integrador (PI) é uma atividade curricular obrigatória em cursos técnicos, de graduação (presencial ou digital) e no ensino médio que conecta a teoria acadêmica à prática profissional. O projeto é uma maneira de interligar diferentes disciplinas do curso em específico (neste caso, engenharia de computação) em uma única tarefa. O atual trabalho apresenta um sensor de luz com um LDR (Light Dependent Resistor, resistor dependente de luz) disposto em um divisor de tensão, que calcula os valores de iluminância de uma sala e envia-os para um website feito com HTML, CSS e JavaScript.
